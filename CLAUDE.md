# AGAPE - Ambiente de Gestão e Apoio Pastoral Especializado

Sistema desktop desenvolvido em Java utilizando arquitetura MVC, padrões GRASP, princípios SOLID e padrões GOF.

---

# Stack Tecnológica

## Linguagem
- Java 21

## Interface
- Java Swing

## Banco de Dados
- MySQL
- JDBC
- MySQL Connector/J

## Ferramentas
- NetBeans ou IntelliJ IDEA
- Git
- GitHub

---

# Arquitetura Obrigatória

O sistema DEVE seguir rigorosamente:

- MVC
- DAO
- SOLID
- GRASP
- GOF (Singleton e Façade)

Conforme exigido pela disciplina.
